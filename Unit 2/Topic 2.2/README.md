# Topic 2.2 — Summary Statistics for Two Categorical Variables

This is a public-safe, independently editable lesson using the same 24-order constructed café data as Topic 2.1. Files include the teaching QMD, a small local-only interactive reference-group explorer, objective mapping, and two focused tests. Eight teacher-authored questions with complete explanations are stored once in the shared original Problem Bank and loaded through the existing accessible reader.

Scope: College Board Fall 2026 AP Statistics CED Topic 2.2, printed page 63, covering joint, marginal and conditional relative frequencies, comparing conditional distributions and justifying contextual claims. Do not upload secure AP Classroom homework, real student data or teacher-only assessments. Native Quarto and browser CI gates must pass before live publication.
