The sample space, written SS, is the set of all possible outcomes for one complete trial.

Three claims the coin does not promise
Claim Think before revealing
“Tails is due after a run of heads.” Does the next toss remember earlier tosses?
“Exactly 50 heads in 100 tosses.” Is probability a quota for each batch?
“More trials fix a wrong model.” What probability does a fair coin actually model?

For independent fair tosses, the next tail probability stays 1/21/2. A finite batch need not have exactly half heads.

More repetitions can stabilize an estimate around the wrong model’s probability; they do not turn a 50% device into a 30% device.

Code Meaning

30–99 No prize: 70 codes

Example: code 23 means Prize; code 49 means No prize. One code models one spin.

Prize and No prize are two labels, but their chances are 30% and 70%, not 50% each. One fair coin toss would give a 50% prize chance, so it is the wrong model here.

Mutually exclusive: no shared outcome

On one roll, let C={2,4,6}C=\{2,4,6\} and D={1,3,5}D=\{1,3,5\}.

Even

C={2,4,6}C=\{2,4,6\}

Odd

D={1,3,5}D=\{1,3,5\}

C∩D=⌀⇒P(C∩D)=0C\cap D=\varnothing\quad\Longrightarrow\quad P(C\cap D)=0

One die result cannot be both even and odd. The events are mutually exclusive, or disjoint.

But “even on roll 1” and “odd on roll 2” can both happen in a two-roll trial. Define the trial before deciding.

A bag contains 3 red and 2 blue marbles. Let R1R_1 mean “first draw is red” and R2R_2 mean “second draw is red.”

P(R1∩R2)=P(R1)P(R2∣R1)P(R_1\cap R_2)=P(R_1)\,P(R_2\mid R_1)

Independent: replace and mix

Return the first marble before drawing again. Knowing its colour does not change the second-red chance.

P(R2∣R1)=35=P(R2)P(R_2\mid R_1)=\frac35=P(R_2)

P(R1∩R2)=35⋅35=0.36P(R_1\cap R_2)=\frac35\cdot\frac35=0.36

Dependent: do not replace

After a red first draw, only 2 red and 2 blue remain. Knowing its colour changes the second-red chance.

Each spin has a 30% prize chance. One complete trial: generate four independent 00–99 codes; allow repeats.

Record Yes if at least one code is 00–29. Example: 23, 49, 82, 35 → Yes.
