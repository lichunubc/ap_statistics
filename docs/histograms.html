1.5 · Build a histogram

Learning goal: Choose and read bins, tally observations, and draw one complete bar for each row of the frequency table.

Step 1 · Choose and read the bins

A histogram groups quantitative observations into ordered intervals called bins. A bar’s width represents an interval of the variable; its height gives the frequency or relative frequency in that interval. We use equal-width bins throughout this lesson.

The commute times run from 5 to 58 minutes. A display spanning 0–60 minutes with width 10 covers every observation:

Boundaries: 0, 10, 20, 30, 40, 50, 60 minutes; six bins of width 10.

number of bins=60−010=6.\text{number of bins}=\frac{60-0}{10}=6.

Seven boundary marks produce six intervals, not seven bins. For a span SS, equal bin width ww, and number of bins kk, S=kwS=kw when the bins exactly partition the span.

Use one consistent endpoint rule

Our convention is left-inclusive and right-exclusive:

a≤x<b.a\leq x<b.

Thus 20 enters 20≤x<3020\leq x<30, not 10≤x<2010\leq x<20. Every observation must enter exactly one bin. Other conventions are possible but must be clearly stated. Here, 58 is below 60 and enters the final bin. A value equal to the final right boundary would require an explicit endpoint exception or an additional bin.

Step 3 · Draw one whole bar per table row

Start the frequency axis at zero and use an even scale. The first row has frequency 2, so draw the first bar to height 2. The next row has frequency 8, so draw the entire next bar to height 8. Adjacent bins share boundaries; their bars touch. An empty bin has zero height.

The six table rows produce whole bars with heights 2, 8, 7, 4, 2, and 1.

The 10-to-under-20-minute bar represents eight students, not an 8-minute commute. Frequency is on one axis; the commute-time interval is on the other. A horizontal histogram reverses the axes: intervals are vertical and frequencies are horizontal.

Frequency or relative frequency?

For a bin with frequency ff in a sample of size nn,

relative frequency=fn,percentage=fn×100%.\text{relative frequency}=\frac{f}{n},\qquad \text{percentage}=\frac{f}{n}\times100\%.

The second bin has 8/24=1/3≈33.3%8/24=1/3\approx33.3\% of the observations. Every bin uses the same denominator, 24. Scaling all bars by the same factor changes the numerical axis, not their relative pattern.

Frequency counts: 2, 8, 7, 4, 2, 1. Their relative frequencies use denominator 24.

A histogram is not a categorical bar chart

These examples use different illustrative samples: travel method for 40 students, and commute time for 24 students.

Travel method: Walk 8, Bicycle 6, Bus 18, Car 8.

Commute-time frequencies: 2, 8, 7, 4, 2, 1.

Feature Categorical bar chart Quantitative histogram
Data axis Category labels Numerical intervals
One bar One category One interval
Order Unordered categories may move Numerical order must remain
Width Usually a design choice A numerical bin width
Blank space Usually separates categories May indicate an empty bin

Identify the variable and read the axis. Whether bars touch is a useful clue, not a sufficient definition.

NoteWhat is no longer visible?

Height 7 for 20≤x<3020\leq x<30 does not reveal the seven exact times. A histogram usually cannot reconstruct the original observations. Use a dotplot, stem-and-leaf plot, or raw list when exact values matter.
