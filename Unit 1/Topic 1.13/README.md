# Topic 1.13 — Experimental Design

Independent public-safe chapter: `topic-1-13.qmd`. Fall 2026 College Board CED printed pp. 51–54; objectives A–D and essential knowledge detailed in `objectives.json`.

This material synthesizes the instructor-approved experimental-design coverage using original text, numbers, an engineering/coatings scenario, and a deterministic 24-panel randomization laboratory. Design topics include comparison, random assignment, replication, direct control, extraneous versus confounding variables, blinding, placebo, completely randomized, randomized blocks, matched pairs, causal inference and generalization. The public chapter describes a hypothetical standard-care-plus-drug versus standard-care-plus-placebo comparison without recommending medical treatment.
